# Pydantic

## 主题说明

学习 Pydantic v2 的建模、运行时校验与数据转换，并将其用于 LangGraph 工作流中的输入检查和 LLM 结构化结果。知识笔记按独立问题组织，保留本轮学习中的疑问、纠正过程、例子与复习答案。

当前进度：已学习到 LangChain 结构化输出；整理时补充的离线示例已验证，真实模型调用、完整条件分流与重试流程尚待实操。
